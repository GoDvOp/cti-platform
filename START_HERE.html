Запустить платформу

Распакуйте архив целиком. Из папки проекта с работающим Docker и Compose:

./start-cti.sh

Открыть панель аналитика. Команда покажет адрес после готовности сервисов.

./start-cti.sh status
./start-cti.sh logs
./start-cti.sh stop

При остановке завершается и веб-панель; данные сохраняются. Инструкция Docker.

Проверить без Docker и интернета

Нужен Python 3.11+; дополнительные пакеты и токены не требуются.

python3 scripts/review.py

После выполнения открыть созданный офлайн-отчёт. До запуска можно посмотреть готовый отчёт снимка и интерактивный граф.

Сценарий демонстрации

  3. Вкладка «Пример»: Equifax 2017, исторический расчёт и доказательные пути.
  4. Источники, даты, предупреждения качества и переход к компании в графе.
