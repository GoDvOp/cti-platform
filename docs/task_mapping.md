Дополнительная часть не является доказательством успешного прогнозирования: точность прогноза и калибровка не измерены, поимённый актуальный рейтинг при недостатке оснований не выдуман. Реализованы необходимые элементы первичной обработки, похожие на задачу № 3, но это не объявляется отдельным полностью выполненным заданием.

Общие требования: итоговый PDF с именем автора, код, инструкция запуска, примеры, источники и ограничения входят в комплект. MITRE и Neo4j — дополнительные средства анализа, а не обязательные условия проверки. Для первого запуска не нужен Docker или секреты.

Прямой сбор с закрытых площадок, сканирование, попытки входа, эксплуатация, покупка доступов и контакты с сотрудниками не выполнялись. ИИ использован при разработке, разметке и подготовке текста; ограничения проверки качества явно указаны.
