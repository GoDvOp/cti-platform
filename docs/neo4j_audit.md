# Проверка проекции Neo4j · 3.0.0

SQLite остаётся основным хранилищем. Проекция Neo4j загружается параметризованными запросами и проверяется обратным чтением.

```sh
./start-cti.sh cli python scripts/audit_graph.py --sync --repeat
```

Аудит проверяет узлы доказательств, направления и концы связей, хеши, статусы, версии, веса, текущие индексы, отдельный исторический результат, исследовательский контекст и обзор CompanyGraph. В текущей процедуре девять сравнений. При повторной загрузке проверяется неизменность содержимого.

В рабочем режиме результаты находятся в data/diagnostics/auto_update/audit.json. В чистой приёмке используется отдельный проект Compose и отдельная папка данных; рабочая база пользователя не затрагивается. Итоговый протокол поставки: [release-3.0.0/docker.json](analysis/release-3.0.0/docker.json).

Наличие HTML-графа не подтверждает доступность Neo4j. Старый успешный аудит не выдаётся за успех нового прохода. Последний успешный результат, отдельная ошибка и heartbeat показаны в панели. Если сервер недоступен, SQLite сохраняет данные, а синхронизация повторяется.
