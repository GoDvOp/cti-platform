# Рабочая панель аналитика

Панель объединяет очередь проверки, карточки компаний, источники, аналитические кейсы и управление паузой/обновлением. Она использует одну модель weighted-graph-v3 в настольном и Docker-режиме.

## Открыть

В Linux открыть привычный ярлык CTI: теперь он запускает браузерную панель. Либо из каталога проекта:

```sh
python3 scripts/control_updates.py
```

Адрес настольной панели — http://127.0.0.1:8765/ . Скрипт повторно использует уже работающую панель и не запускает второго сборщика. Если рабочая база ещё отсутствует, открывается демонстрация на отдельной копии публичного снимка и дополнительного кейса GitLab. Оригинальная review-база и форма разметки для этого не меняются.

Явная демонстрация без рабочего сбора:

```sh
python3 -m app.workbench --offline
```

Обычный запуск сборщика в Linux по-прежнему выполняется пользовательской службой; установка и первый запуск описаны в auto_update.md. Docker-вариант запускает и сборщик, и панель:

```sh
./start-cti.sh
```

Панель Docker — http://127.0.0.1:8766/ . На Linux переход на Docker закрывает отдельную настольную панель этой папки; после остановки Docker веб-сервер не остаётся работать. `CTI_WORKBENCH_PORT` изменяет опубликованный порт Docker. Оба интерфейса читают ту же папку data и показывают фактический режим сборщика. Самостоятельная команда `python3 -m app.workbench --port 8875` подходит для отдельного локального просмотра.

## Сценарий аналитика

1. Посмотреть режим, фазу сборщика и время последнего успешного аудита Neo4j. Старое успешное подтверждение не выдаётся за текущий успешный проход. Сетевые ошибки сохраняются отдельно от данных.
2. Открыть «Требуют внимания». Очередь ранжирует задачи проверки: свежая техническая гипотеза, обновление внутри контура, проверка свежего адресного сообщения. Исторические и просроченные сообщения не поднимаются как свежие сигналы.
3. Выбрать компанию. Карточка объясняет причину приоритета, разделяет интерес атакующих и технический контекст, показывает неизвестные значения, контраргументы и следующее действие.
4. Проверить основные источники и раскрыть остальные при необходимости. Дата публикации, отдельное наблюдение страницы и время сохранения показаны раздельно. Ручные пересказы и проверка ассистентом не выдаются за автоматический сбор или независимую экспертизу.
5. Открыть выбранную компанию в графе либо полный разбор кейса. Проверенные, непроверенные и отклонённые связи различаются; исключённые пути доступны отдельно.

Значения индексов — сила доступных оснований, не вероятность атаки. «Нет данных» остаётся неизвестностью. Публичная страница сервиса не доказывает доступность уязвимого обработчика, а применимость CVE требует проверки фактической версии.

В разделе «Источники» показаны только источники, включённые в автоматический сбор. Отключённые и удалённые из конфигурации источники не занимают строки в рабочем списке. Их сохранённые публикации и доказательства остаются в карточках компаний и полном аудите источников. Ошибки включённых источников по-прежнему видны.

## Обновление и пауза

«Обновить панель» только перечитывает данные. «Обновить данные» отправляет запрос работающему сборщику; интервалы источников сохраняются, а граф пересобирается с обратной проверкой.

«Приостановить сбор» завершает текущий проход и приостанавливает последующие. Процесс продолжает сообщать состояние и обслуживать общий файл управления. «Продолжить сбор» снимает паузу. Пауза сохраняется при перезапуске процесса; это не остановка systemd или Docker. Если сборщик выключен или открыт демонстрационный снимок, эти кнопки недоступны. Запуск выбранного механизма выполняется обычным способом из инструкций, без попытки скрыто переключить режим или создать второго сборщика.

## Твоя разметка

Если разметка уже начата, продолжать в прежней вкладке. Открытая из панели форма имеет другой адрес браузера: автоматический перенос сохранённого прогресса между адресами не предполагается. Для переноса сначала скачать промежуточный JSON из прежней формы и восстановить его в новой.

После завершения скачать итоговый JSON и выбрать «Загрузить разметку» в панели. Проверяется исходный фиксированный корпус из 30 текстов, а не новый кейс GitLab. До успешной проверки неполной или чужой разметкой прежний результат не заменяется. Корпус, ответы алгоритма, форма и исходный снимок сохраняются неизменными.

## Данные и границы локального интерфейса

Чтение аналитики выполняется на согласованной SQLite-копии: HTTP-запрос не мигрирует рабочую базу и не записывает оценки в неё. Панель публикует только заданные маршруты и известные артефакты кейсов. Файлы .env, рабочая SQLite и ответы алгоритма через HTTP не раздаются. В контейнер панели не передаётся пароль Neo4j; Docker-сокет не монтируется. Управление работает через общий каталог data и одинаково используется обоими сборщиками.

Панель предназначена для локального компьютера. Docker публикует её только на 127.0.0.1. Запросы действия требуют токен открытой страницы и отклоняются при чужом Origin/Host. Внешние публикации отображаются как текст; небезопасные схемы ссылок не активируются.

Браузерные проверки и скриншоты — docs/analysis/release-3.0.0/browser. Контейнерная приёмка — docs/analysis/release-3.0.0/docker.json.

## Исторический пример

Вкладка «Пример» открывает Equifax 2017. Учебная реконструкция на 15.09.2017 использует два исторических источника: сообщение Equifax и бюллетень Apache S2-045. Показаны интерес и отдельное подтверждение исторической технической цепочки; основная техническая гипотеза не заменяется этим результатом.

Для исторической эксплуатации нужны инцидент, пострадавшая компания, продукт и CVE с подтверждёнными связями. Её качество не понижается только из-за неизвестного номера установленной версии, но не подтверждает нынешнюю уязвимость компании. Сбор и проверка документов выполнены позднее: пример остаётся учебной реконструкцией, а не результатом работы системы в 2017 году. Реальные даты сбора и проверок сохранены.

Карточки показывают предупреждения, если в старых связях отсутствуют уверенность или тип основания. В раскрытых путях видно, от какой даты считается давность: наблюдения, периода события или публикации-приближения. Для новых подтверждений эти поля качества обязательны. Прямая ссылка: `http://127.0.0.1:8766/#equifax`.
