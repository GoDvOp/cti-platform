# Вывод о потенциальных целях: группа для мониторинга

Срез 24.10.2026. Результат — качественная гипотеза мониторинга, не оценка вероятности атаки.

Выбранная группа: российские организации с публично подтверждённым использованием корпоративной VPN и локального Microsoft Exchange. Для неё целесообразно приоритизировать поиск новых адресных сигналов и проверку доступных сведений о внедрениях.

Основание: в автоматически собранном списке Securelist найден материал о NightEagle; полный [отчёт Kaspersky от 16.09.2026](https://securelist.ru/tr/nighteagle-apt-ghostcontainer-and-tunneling/117051/) затем изучен отдельно. Он связывает расследованные российские эпизоды с использованием скомпрометированных VPN-учётных записей и серверов Exchange. Это исследовательская выборка, а не перепись всех атак.

Нельзя переносить вывод на любую компанию, у которой просто встречается слово Exchange. В нашем каталоге нет достаточного подтверждения текущей принадлежности конкретных организаций к этой группе, поэтому поимённый список не сформирован. Наличие компонента, связанного с CVE-2020-0688, не доказывает её эксплуатацию в каждом эпизоде; точный способ доставки бэкдора источник оставляет неустановленным.

Следующий пассивный шаг — проверять датированные официальные кейсы внедрения и новые адресные сообщения. Активные проверки инфраструктуры, покупка доступов, проверка учётных записей и контакты с сотрудниками не проводятся.

Машиночитаемое основание, IDs публикаций и ограничения: monitoring_cohort.json. Автоматическое обнаружение и ручной разбор отмечены раздельно. Эта гипотеза — конкретный результат дополнительной части задачи № 1; её прогностическая полезность не проверена.
