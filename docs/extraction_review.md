# Проверка извлечения связей человеком

Открыть [форму без ответов алгоритма](../evaluation/blind_review.html). Она работает локально без сети и показывает 30 зафиксированных входов, каталог компаний и ПО, инструкцию и поля разметки. В HTML не включены ответы алгоритма, структурированные подсказки из метаданных или прежние аналитические проверки. Ссылки на первоисточники доступны для контекста; оценка относится к сохранённому тексту, а не к изменяющейся странице.

Нужно отметить упомянутые продукты, CVE/BDU и явно выраженные направленные связи шести видов. Для связи указывается дословный фрагмент. Совместное упоминание не равно использованию; отрицание, план внедрения и участие в bug bounty не являются фактом атаки. Пустой результат считается отрицательным примером только после отметки «Проверен полностью». Текст с недостаточным контекстом можно исключить с объяснением; число исключений попадёт в отчёт.

## Происхождение выборки и ответов

Корпус строится из публичного снимка по заранее заданным квотам источников, затем по SHA-256 с фиксированным seed. Состав не выбирается по успехам или ошибкам алгоритма. Публикации и хеши текстов из прежнего пилота классификации исключены. Для отдельных статей также исключается повтор URL; записи каталогов CISA и TrueConf различаются ID и хешем, хотя имеют общую ссылку каталога. Это 30 сохранённых единиц текста, а не 30 независимых издателей.

Часть входов — короткие пересказы, анонсы или карточки каталога. Тип сохранённого входа виден в форме. Материалы могли использоваться при разработке, поэтому выборка не объявляется скрытым holdout или проверкой переноса на будущие источники. Извлечение группировок и атрибуции в эти шесть видов связей не входит.

Файлы `evaluation/extraction_corpus.json` и `extraction_predictions.json` фиксируют входы, каталоги, версии текстов, хеш кода извлечения и ответы алгоритма до человеческой разметки. Рецензенту не следует открывать файл ответов до завершения проверки. Форма содержит только публичную часть корпуса. Пересоздание другого корпуса в том же каталоге запрещено; для нового раунда нужен отдельный каталог.

## Кто проверяет

Рецензент указывает имя или псевдоним и отношение к проекту. Проверка автором проекта получает статус `blind_project_author_review_not_external`. Проверка другим человеком — `external_reviewer_self_declared`: программа фиксирует заявление о независимости, но не проверяет личность. Нельзя назвать внешней экспертизой разметку ассистентом или автором проекта. Ответы алгоритма и помощь ИИ при разметке исключаются подтверждением рецензента.

## Завершение без терминала

Прогресс автоматически сохраняется в браузере. Можно скачать промежуточный JSON и продолжить позже через поле восстановления. Перед расчётом нужно проверить или обоснованно исключить каждый текст.

Скачать итоговый JSON, заново открыть панель «CTI — граф и автообновление», нажать **«Загрузить разметку»** и выбрать скачанный файл. Программа проверит соответствие корпуса, хеши текстов, полноту, концы связей и доказательные фрагменты. Затем откроется [отчёт](../data/processed/extraction_evaluation/extraction.html). Разметка не подтверждает связи в рабочем графе автоматически.

Не нужно загружать JSON в чат. Проверка выполняется локально. Прежняя принятая версия сохраняется в истории; локальное принятие разметки не обновляет уже собранный ZIP. Перед отправкой комплекта результат следует включить в новый проверенный архив.

## Как считаются результаты

Для направленной связи совпасть должны публикация, тип и оба конца. Разворот стрелки даёт ложноположительный и ложноотрицательный результаты. Отдельно считаются совпадения упоминаний продуктов каталога и CVE/BDU. Извлечение кандидата и подтверждение истинности утверждения — разные задачи.

Micro Precision = TP / (TP + FP), Recall = TP / (TP + FN), F1 = 2TP / (2TP + FP + FN). Отчёт показывает TP/FP/FN, результаты по типам, долю полностью совпавших документов и каждую ошибку. Если знаменатель отсутствует, значение остаётся неизвестным. Непроверенные тексты не становятся отрицательными примерами. До человеческой разметки метрики имеют значение null и статус «ожидает разметки».

Это проверка извлечения на ограниченном корпусе, не измерение вероятности атаки, Precision@K, полноты мониторинга или истинности исходных публикаций.
